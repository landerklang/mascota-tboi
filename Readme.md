## Version en español

# Mascota virtual de binding of isaac

bienvenido este es mi primer proyecto
una mascota virtual de los personajes de _the binding of isaac_

## Como iniciar

<!-- Intalar dependencia  -->

- `npm i`

<!-- iniciar programa -->

- `npm start`

puedes reemplazar al personajes si vas a la carpeta imagenes en la carpeta renderer dentro de src.
no se olvide de revizar que el archivo html indique correctamente al archivo que quiere usted que se muestre

Version 1.0

Esta es la primera version del proyecto el personaje se puede mover al arrastrar a la mascotas

## Herramientas utilizadas

- **Electron**:Para crear la ventana transparente y sin bordes.

- **TypeScript**: Para un desarrollo más seguro y tipado.
- **Node.js (fs, path)**: Para scripts de construcción (build).
